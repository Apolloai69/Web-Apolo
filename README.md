# APOLO Marketing · Web

Web estática de APOLO Marketing (agencia de marketing en redes sociales, Madrid).

## Estructura
- `index.html` — página principal
- `blog.html` y `articulo.html` — blog con 20 artículos (`js/articles.js`) y portadas ilustradas (`js/covers.js`)
- `legal.html` — aviso legal, privacidad, cookies y condiciones
- `css/styles.css` — estilos y animaciones
- `js/main.js` — interacciones
- `img/vehiculos/` — fotos de vehículos con el fondo recortado

## Ver en local
```bash
python3 -m http.server 8000
```
y abre http://localhost:8000

## Publicar con GitHub Pages
Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
